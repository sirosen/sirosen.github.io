# pip-tools v7.6.1

Today marks [`pip-tools` v7.6.1](https://github.com/jazzband/pip-tools/releases/tag/v7.6.1).

This one is quite small.
Mostly we improved compatibility, making things work with pip v26.2 and adding
in a missing `typing-extensions` dependency for older Python versions.

There are various other bits of small cleanup.
I had the pleasure of meeting [@psthindal](https://github.com/sponsors/psthindal)
at EuroPython, and he helped us refactor our bug report template!
Docs also continue to improve: we now have a
[How-Tos Section](https://pip-tools.readthedocs.io/en/stable/how-to/).

Like I said though, this release is quite small! That's all for now -- we'll see you next time.
